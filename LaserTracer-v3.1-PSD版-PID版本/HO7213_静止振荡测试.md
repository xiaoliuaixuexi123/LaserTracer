# HO7213 静止振荡分级测试

## 目的

依次隔离机械安装、电机内部三闭环和PSD外环，判断静止振荡来自哪一层。每次只改变一组参数，两个轴分开测试并保存日志。

## 安全基线

- 电机：HO7213，CANFD，21极对，位置模式。
- 第二轮位置环提速测试值：进入位置模式后，pitch轴Kp=24、Kd=208，yaw轴Kp=14、Kd=112；速度保持2rad/s，电流保持3A。
- 位置速度上限：1.0 rad/s。
- 电流上限：3.0 A。
- 确保转台无硬限位干涉、线缆拉扯和松动，急停/失能可立即操作。
- 任一轴持续顶到3.0 A、温度快速上升、振幅持续增加或出现错误码时，立即停止并失能。

启动或更新参数后，应看到类似日志：

```text
[HO7213参数][跟踪启动检查] motor1 型号=HO7213 CAN=0x001 极对数=21 mode=2 Kp=24 Kd=208 速度上限=2.000rad/s 电流上限=3.000A
[HO7213参数][跟踪启动检查] motor2 型号=HO7213 CAN=0x002 极对数=21 mode=2 Kp=14 Kd=112 速度上限=2.000rad/s 电流上限=3.000A
```

## 第一级：机械与电机内部位置环

关闭PSD跟踪，只启用一个电机，另一个轴保持不动。

1. 查询并记录当前位置。
2. 向当前反馈位置发送相同位置，保持10秒。
3. 分别发送 `+0.05°`、回零、`-0.05°`，每次保持10秒。
4. 分别发送 `+0.20°`、回零、`-0.20°`，每次保持10秒。
5. 对另一个轴重复测试。

记录位置、速度、电流、温度和是否出现周期性正负速度。固定位置时若仍持续振荡，问题位于机械结构或电机内部位置环，与PSD外环无关。

判定建议：

- 不要再用通用20/20参数覆盖这套转台的实机整定值。
- 若关闭PSD后仍振荡，立即停止，不在线盲调内部PD；先检查机械负载、安装和两轴参数是否被错误覆盖。
- 若关闭PSD后稳定，则保持原有内部PD不动，只调整PSD外环。
- 两轴表现不同：分别调参，不要为了数值一致牺牲稳定性。

## 第二级：PSD只观测，不控制

电机保持固定位置，不启动PSD跟踪，使用下位机独立采样工具连续记录20秒：

```bash
cd /home/wheeltec/Documents/PSD/10_position_multirate_fast
sudo /usr/bin/python3 ad7606_reader.py \
  --rate-hz 500 --print-hz 10 --duration 20 --strict-busy \
  --x-offset -0.0055 --y-offset 0.0158 --sum-offset 0.0608 \
  --sum-min 0.2 --sum-max 4.5 --csv /tmp/psd_static_20s.csv
```

检查：

- `SUM`是否稳定并远离0.2 V和4.5 V边界。
- X/Y归一化值的峰峰值和标准差。
- 是否出现ADC BUSY超时或PSD无效样本。
- 光斑、支架和线缆完全静止时，误差方向是否仍快速翻转。

若电机反馈稳定而PSD误差大幅变化，应先处理光路、PSD饱和、接线或采样问题。

## 第三级：保守PSD外环

只有前两级通过后才启动PSD闭环。首次闭环建议使用：

- 关闭预测：`prediction_horizon_s=0.0`。
- 外环远区P：0.25。
- 远区单次修正上限：0.030°。
- 远区目标领先上限：0.080°。
- 电机内部Kp/Kd继续保持两轴原有实机整定值。

静止运行30秒，记录：实际采样、实际控制、运动命令、反向制动次数、目标领先、反馈位置和PSD误差。

通过标准：误差总体收敛，目标领先不长期卡在±0.080°，反向制动不连续出现，进入中心后不再发生持续正负往返。

## 第四级：逐步提高响应

每次只调整一个参数，并至少观察30秒：

1. 外环P按0.25、0.30、0.35逐级增加。
2. 确认无振荡后，再把远区修正上限按0.030°、0.040°逐级增加。
3. 最后才启用预测，从5 ms开始；不要直接恢复30 ms。
4. 任一级出现持续振荡，立即退回上一组稳定参数。

## 快速定位

- PSD关闭仍振荡：机械或HO7213内部PD问题。
- PSD关闭稳定，PSD开启后振荡：PSD外环P、预测、领先量或二维校正矩阵问题。
- 单轴稳定、双轴振荡：重点检查二维校正矩阵和结构耦合。
- 误差越来越大而不是往返：检查电机方向、轴映射和校正矩阵符号。
