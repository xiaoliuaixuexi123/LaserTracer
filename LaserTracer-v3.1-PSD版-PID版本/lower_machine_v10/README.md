# 10号：分区多速率高速位置跟踪

## CANFD自动上传核查（auto-feedback-v13）

如果需要完全绕开下位机服务和上位机，先停止服务，使用独立安全Demo：

```text
python3 canfd_auto_upload_demo.py --port /dev/ttyACM0
```

Windows串口示例为 `--port COM5`。脚本只发送适配器初始化、参数只读和
Index06上传开关，不发送位置、使能、清零或PD参数；自动测试电机1/2的
8字节及16字节开关格式，退出前请求关闭上传，并保存带时间戳的JSON原始日志。

测试按钮使用 `canfd_upload_diagnostics.py`，更新时需连同服务器文件一起部署。
先停止跟踪。测试仅发送手册的参数读取和Index06上传开关；不发送位置、速度、
使能或PID命令，不在测试期间重开CAN通道。默认双轴约14秒。

过去的“扩展帧只读验证”只要求收到任意帧，不能证明参数读取成功。
v13依照20260710手册第50页核对标准FD帧的电机ID、01/Index头和参数布局。
用户提供的 `d064A0000000000FFFFFFFB007E0201002501` 是普通状态帧，
不是温度读取的专用参数应答。参数应答不会再作为位置反馈写入缓存。

每种长度均执行关闭/开启/关闭对照，同时记录原始RX、实际TX和50ms之后的
四个时间段帧数。只有关闭期间安静、开启后持续回传、再关闭后安静，才确认
周期上传；通信返回一帧和测试动作的success都不代表功能开启成功。
`all_verified`表示两轴测试结论；`cleanup_errors`表示关闭请求是否写入失败。
测试结束请求关闭上传，不会重新开启失败格式。成功格式保留在本进程中，
随后跟踪启动仍需重新开启并验证。该流程尚待硬件验证，不宣称1.54固件存在缺陷。

离线核查：

```text
python -m unittest discover -s lower_machine_v10 -p test_canfd_upload_diagnostics.py -v
python lower_machine_v10/self_test.py
```

第10版基于08号异步位置模式，解决“远区速度提高后中心持续跳动”的问题。它仍保持电机位置模式，不使用速度模式。

## 控制架构

1. PSD目标采样500 Hz，主控制与双电机发送调度目标250 Hz；采样线程只发布最新读数，控制计算在250 Hz线程完成。
2. 两轴CANFD目标批量写入，电机反馈由独立线程接收。
3. 三个误差分区均允许最高250 Hz调度；精细区单步0.001°，用于抑制中心附近量化往返。
4. 中区单步最大0.012°、动态领先0.006～0.030°，每次以反馈位置重置目标。
5. 误差超过4倍死区即进入远区；远区单步最大0.060°、动态领先0.040～0.160°。
6. 增量步长以200 Hz为物理增益基准，并按真实命令间隔缩放；250 Hz连续下发时步长约乘0.8，避免提频后等效增益增大。
7. 预测只在远区启用，预测时间30 ms；微分使用PSD样本的真实时间戳，掉线恢复时清空旧微分状态。
8. 动态领先量按当前误差比例连续计算：刚进入远区时接近0.040°，误差达到12倍死区时升到0.160°；远区累计目标不会在制动结束后被二次重置。
9. 接近中心阻尼时间15 ms：PSD正在回中心时按接近速度削弱控制误差，最大削弱量为1.5倍死区且不会反向。
10. 只有整个位移向量夹角超过120°且幅值超过0.010°，连续确认3次后才制动25 ms；单轴符号跳变不再打断运动。
11. 中心死区设置为X=0.012、Y=0.012；连续8个样本进入即锁定。
12. 锁定后连续16个样本越过2倍释放边界才重新运动；中心主动保持最短间隔250 ms，避免重复取消目标。
13. 共享状态限制为10 Hz刷新，运动、状态和电机链路文本日志均限制为1 Hz，减少锁和打印对实时线程的抢占。

## 关键参数

- 全局最大单周期修正：0.060°
- 远区动态领先：0.040～0.160°（4～12倍死区）
- 远区最大命令频率：250 Hz
- 中区动态领先：0.006～0.030°
- 中区最大命令频率：250 Hz
- 精细区目标领先：0.001°
- 精细区最大命令频率：250 Hz
- 增量步长物理增益基准：200 Hz
- 反向制动：向量反向连续3次确认后25 ms
- 预测前馈：仅远区，30 ms自适应门控，最大3倍死区预测量
- 接近阻尼：15 ms，最大1.5倍死区
- SUM有效范围：0.2～4.5 V
- HO7213：CANFD 21极对；保留两轴原有的实机PD参数和3 A电流上限，不使用通用20/20参数覆盖实机整定值

静止振荡排查按仓库根目录 `HO7213_静止振荡测试.md` 执行；必须先确认电机内部位置环稳定，再调整PSD外环。
